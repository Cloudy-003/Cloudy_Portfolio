# 🗄️ HR Employee SQL Analysis

## 📖 About the Project

This project demonstrates my SQL skills by analyzing an HR Employee dataset using **MySQL**. The objective of this project is to solve real-world business problems by writing SQL queries that extract meaningful insights from employee data.

Throughout this project, I practiced essential SQL concepts such as data filtering, sorting, grouping, aggregation, subqueries, and window functions. The analysis includes employee demographics, salary insights, departmental statistics, attrition analysis, overtime analysis, and employee salary rankings.

This project serves as a part of my Data Analytics portfolio and reflects my understanding of SQL fundamentals and intermediate querying techniques.
