
# Retail Sales Analysis (Excel)

## Project Overview
This project analyzes retail sales performance using Microsoft Excel. The objective was to identify sales trends, profitable categories, top-performing regions, and key business insights through Pivot Tables, Pivot Charts, and dashboarding.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Net Profit

## Analysis Performed
- Sales by Region
- Profit by Category
- Technology Sub-Category Analysis
- Monthly Sales Trend
- Average Shipping Days
- Most Profitable State

## Key Findings
- West region generated the highest sales.
- Technology was the most profitable category.
- Copiers generated the highest profit among technology sub-categories.
- Bookcases and Tables generated losses.
- Sales peaked during the final quarter, especially in November.
